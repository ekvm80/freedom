Three Remote Paths

There are three ways in from outside, and they do different jobs. This distinction matters more than anything else in daily use.

Delegate

Telegram · Slack

Connects to Hermes on the Mac (Hermes). Hand something off and it works and reports back.

For sending a receipt photo, a voice recording or a link and just getting the result. Works from the laptop too — no remote session needed, one line is enough.

Resume session

Orca mobile app

Connects to Orca on the Lab Desktop (Freedom). You join the session and carry on.

For continuing work you started on the Desktop, or checking on its progress. The conversation is still there.

Screen control

Chrome Remote Desktop

Takes over the whole screen of the Mac or the Lab Desktop.

For driving the Desktop or Mac from the laptop, and for anything that needs several files open at once.

Rule of thumb: if one line of instruction finishes the job, use Telegram; if you need a back-and-forth, use Orca mobile; if you need to see the screen, use Remote Desktop. Slack is used only occasionally, when something has to be shared to a lab channel.

⚠ Why Hermes lives only on the Mac — preventing data loss

Hermes Agent is an autonomous agent that can create, modify and delete files on its own. That power comes with room for unintended file operations.

So autonomous execution is confined to a single machine, and the Lab Desktop and laptop stay safe zones where a human reviews each step.

This is not a limitation — it is a deliberate safeguard. The Desktop and laptop have all three MCP servers too, so there is no difference in practical capability; only the “does it for you” automation is confined to the Mac.

Security & Data Protection

Handling secrets

If an API key or bot token leaks, someone else can spend your credits or drive your agent remotely.

1
Restrict file permissions — config files holding keys should be readable only by you (chmod 600)
2
Exclude from cloud sync — never back up the entire home directory; config files go up with it
3
Never write keys into documents — no notes, messages or chat prompts should contain real key values
4
The KOSIS key is on every device — the MCP servers are installed on three machines, so all three must follow these rules

Preventing data loss — two lines of defence

First line

Confine autonomous execution

Hermes stays on one machine. The Desktop and laptop are places where a human reviews each step.

Second line

Concentrate backup effort

The research corpus (Wiki, ECC Atlas, papers, grant files) all lives on the Mac, so backing up the Mac is backing up everything.

⚠ Note — concentration remains Splitting permissions does not change the fact that the assets sit in one place. If the Mac's backup stops, that becomes a single point of failure. Re-run the backup items in the verification checklist periodically.

Architecture summary

Orca/Antigravity with Claude and Gemini subscriptions, the three Korea-specific MCP servers (43 tools) and the Google Drive · NotebookLM · Notion · Gmail/Calendar integrations are built identically across the Mac, Lab Desktop and laptop, giving the same working capability anywhere (Freedom). On the Mac alone, Hermes Agent and the Telegram/Slack gateway add one more layer, run as a delegation-style assistant (Hermes). There are three remote paths — delegate to the assistant over Telegram/Slack, resume a Desktop session through Orca mobile, and take full screen control through Chrome Remote Desktop. Models run on Timely first and fail over to OpenRouter, while anything that needs Claude or Gemini for a long stretch is opened in subscription-authenticated Freedom — even on the Mac — so it stays flat-rate. The result: the benefits of automation, uniform capability across devices, and data safety, all at once.

By Work Area

①Academic research and writing Multi-AI cross-review · manuscript revision · turning reading into assets›

A. Planning and multi-AI cross-review

  • Reviewing from a top-tier journal's angle: rather than relying on one model, review in parallel from three or more perspectives — Claude (logic and prose), GPT (structure and completeness), Gemini (data and factual accuracy).
  • Cost-efficient division: long Claude/Gemini reviews run in Freedom at flat rate; GPT-side review plus collation, comparison tables and file saving are handled by Hermes.
  • When shortlisting English titles, the academic rationale and the editor's-eye reasoning are analysed together before choosing.

B. Manuscript revision and redline under a strict style guide

  • Automatic application of a strict academic style: passive voice for Methods (past passive), no personal subjects, no AI boilerplate, consistent number-and-unit notation.
  • Division of labour: the intellectual work of shaping sentences goes to Freedom; applying the agreed edits without damaging the original formatting, and saving them, goes to Hermes.
  • Possible anywhere: kordoc is on every device, so HWPX formatting can be edited from the Desktop or laptop too. Filing the result into the right folder automatically, however, is A's job.

C. Turning reading into permanent assets — Research Wiki & ECC Atlas

  • Papers that have been read are accumulated automatically into the Research Wiki on the Mac, with cross-links generated.
  • The ECC Atlas structures self-healing and ECC knowledge as a map, ready to cite when writing the background section of a proposal.
  • Bulk translation and consistency-check drafts are produced in Freedom; the final accumulation and indexing is handled by Hermes.
These two assets exist only on the Mac. Every time a paper is read, Hermes accumulates and indexes it — so they live where that automation runs. To view the wiki from the Desktop or laptop, connect via Chrome Remote Desktop or ask through Telegram.
②Lab management and faculty administration Expense settlement · CV updates · Korean public-sector forms›
This area is mostly A's work. The tools exist on every device, but repeating a fixed procedure and filing the result away requires automation.

A. Storing a short record of a research-expense meeting

  • Only five fields are taken from the receipt: the receipt itself, date and time, location (Engineering Bldg. 2, Room 213), meeting duration (one hour, starting two hours before payment) and meeting content.
  • They are kept in 회의비기록/ under the project directory (Projects/), alongside the original receipt.
  • When settlement or reporting is actually needed, it is all pulled up at once and turned into a table or paperwork. The point is not to finish the minutes on the spot.

B. Live updates to research output and CV

  • When a new paper is published, the DOI is verified through the Crossref API and added to the top of the official CV (.docx) in standard format, with a backup kept.
  • Documents submitted to public agencies and the university are structured into metadata / text / Obsidian indexes for storage.

C. Korean public and academic forms (HWPX/PDF)

  • Filling blanks in HWPX/PDF forms, placing seal and signature anchors automatically, masking personal data.
  • When revising design codes (KDS) and standard specifications (KCS), korean-law cross-checks the cited provisions.
  • The Desktop and laptop can do all of this too — in a hurry, grab whichever computer is in front of you.

03 · System setup guide

Setup Guide

There are two tracks, and you must do the Freedom track before the Hermes track. B is the foundation for every device; A adds one layer on the Mac alone. Finishing B first also means you can ask the Claude you built there for help while doing A.

Before You Start

This guide is not a copy-and-paste command manual

Installation commands and config file formats change within months as versions move on. Pinning exact commands here would make this guide actively wrong within half a year and send you further astray. Machines also differ, so the same command works on one computer and fails on another.

So this guide tells you only what to do, why, and in what order. Ask an AI for the specific commands and settings as you go.

2Install Hermes Agent Includes: “what is a virtual environment? does macOS itself get installed into one?”›
💬 First — what is a “virtual environment”? Does macOS get installed into one?

No. This is a common misunderstanding: a virtual environment does not virtualise your operating system.

A virtual environment (venv) is a separate box that holds Python parts (libraries). macOS itself is entirely unaffected.

Why keep a separate box at all —

· macOS uses Python for its own internal functions. Installing things there until versions clash can break operating-system tools. (Recent macOS versions block installing into the system Python outright.)

· If something does go wrong later, deleting that one folder and recreating it restores a clean state.

macOSWindows
Is a venv needed?Required (the OS uses Python)Recommended (not for the OS, but for tidiness)
What gets isolated?Only Python libraries (not the OS)Only Python libraries
How to activatethe source commandWSL is the same as macOS; native Windows differs
In short: you are not “installing macOS into a virtual environment” — you are keeping the Python parts in their own box.

Folder Structure & Naming Paths

The single most important thing when handing work to an AI is stating exactly which folder and which file. Leave the folder out and it hunts in the wrong place or has to ask, and you lose time.

/Users/bylee/ ├── Documents/ │ ├── Professor_Profile/ │ │ ├── Admin_Documents/ # admin paperwork, seal image (seal.png) │ │ └── Projects/ # one folder per research project │ │ └── 집단연구2025/ │ │ └── 회의비기록/ # five-field records + receipt archive │ ├── Research_Papers/ │ │ └── My_Published_Papers/ # my own published papers │ ├── Research_Knowledge/ │ │ ├── llm_wiki/ # 📚 Research Wiki (Mac only) │ │ └── ecc_atlas/ # 🧭 ECC Atlas (Mac only) │ ├── Knowledge_Archive/ # saved links and articles │ └── Standards_Revision/ # design code / specification revisions └── Downloads/ # scratch files, incoming paper PDFs

The Research Wiki and ECC Atlas exist only on the Mac. They are not visible from the Desktop or laptop. Connect remotely or ask through Telegram when you need them.

Route other working files through Google Drive. Drive is connected on every device, making it the simplest way to pick up on the Desktop what you started on the Mac.

Three ways to specify a folder

①

Paste the full path

The most reliable. In Finder, right-click a file and hold option — “Copy as Pathname” appears.

/Users/bylee/Documents/Research_Papers/My_Published_Papers/

②

Shorten with ~

~ stands for /Users/bylee.

~/Documents/Research_Papers/

③

Say where to save it too

“Analyse this” alone puts the result on screen and nothing more. Add “…and save it to folder X as Y.md.”

On Telegram, typing paths is awkward, so plain names like “the usual meeting-expense folder” or “the papers folder” work fine. The assistant remembers the folders you use regularly.

Cost & Safety Habits

💰 Three habits that keep costs down

①

Long sessions always go to Orca/Antigravity

Including on the Mac. Same model, but subscription auth is flat rate and API is metered. This one habit accounts for most of the cost.

②

Check the Timely credit balance regularly

While credits remain, Hermes is effectively free. When they run out, move heavy work to Freedom.

③

Keep Hermes on short, hands-on jobs

Receipts, file filing, wiki accumulation, applying formatting — these end in a short exchange, so metered billing barely registers, and they are impossible without automation anyway.

🔐 Three habits that keep things safe

①

Do not install Hermes on the Desktop or laptop

The MCP servers are already there, so nothing is lost in capability. This principle is the first line of defence for your data.

②

Backing up the Mac is backing up everything

The Research Wiki, ECC Atlas, papers and grant files all live there. Check regularly that Google Drive sync is actually running.

③

Manage API keys on all three machines

The MCP servers are on three machines, so the KOSIS key is in three places. Verify file permissions and backup exclusion on each.
